# Ziggy — operating rules

Ziggy is a per-tenant social media manager: brand → HyperFrames videos → Postproxy posts → inbox →
autopilot. This file is for agents working **on** this repo; `skill/SKILL.md` is for agents
working **with** Ziggy.

## Layout

- `skill/index.js` — the CLI. Thin: argument parsing, output, and the hush re-exec. Logic lives in
  `skill/scripts/*.mjs`, each one a module with no side effects on import.
- `skill/templates/` — HyperFrames templates (`hyperframes/<name>/{host,sub}.html.tpl`) and the
  static social compositions. `__TOKEN__` placeholders, filled by `video.mjs` / `assets.mjs`.
- `tenants/<slug>/` — versioned tenant definitions. Never put secrets, renders or fonts here.
- `skill/test/` — `node:test`. Every external dependency is faked: mock Postproxy on localhost
  (`helpers.mjs`), fake `hush`, fake agent, fake HyperFrames CLI via `ZIGGY_HYPERFRAMES_BIN`.

## Rules

- Node ESM, `type: "module"`, no runtime dependencies. Node 20+ (fetch, FormData, `openAsBlob`).
- Output to stdout for the agent; `--json` must stay valid JSON (progress goes to stderr).
- Secrets: never read, print, store or log a key. Keys reach commands only as `POSTPROXY_API_KEY`
  in the environment, injected by `hush run`. Do not add a config field for a key.
- Every backend/API function gets an integration test against the mock server before it ships.
- Run the CLI in tests with `runCli` (async). A `spawnSync` deadlocks the in-process mock server.
- HyperFrames projects generated by `video.mjs` must pass `npx hyperframes check` unchanged:
  one paused GSAP timeline per composition, no CSS-transform/GSAP conflicts, fonts shipped locally,
  `data-layout-allow-overflow` on intentional masks. Test a template change with a real render.
- Keep per-tenant isolation: a command takes one slug and touches only that tenant's paths and secret.
- MIT license. No co-authorship lines in commits, PRs or comments.

## Commands

```bash
cd skill && npm run check && npm test
node skill/index.js doctor <tenant>
node skill/index.js video <tenant> <campaign> --dry-run   # scaffold only
```
